## 一、业务需求
 


假设我们有一个电商平台，现计划开展一个秒杀活动。
 


核心要求是**一人一单**且**不能超卖**。
 


请你设计并实现该业务。
 


---
 


## 二、分析
 


### （一）sql 表是否需要改动？
 


考虑到电商平台已有用户表和商品表，但秒杀活动有其特殊性：
 


- 秒杀商品的库存管理需要高性能和独立性，不宜直接操作海量数据的常规商品表。因此，需要**新增秒杀商品表 (`shop_seckill`)**来管理秒杀商品的专属信息。
- 秒杀场景下，为了提升并发处理能力，避免下单时立即操作库存带来的性能瓶颈，应**新增秒杀订单表 (`order`)**。秒杀订单处理流程将优先保证快速响应，库存扣减采用异步方式。
 


最后， 为应对写入压力，对这两张表进行**水平分表**。采用对 10 取模的方式，将每张表拆分为**10 张物理表**，以分散单表负载。
 


### （二）如何应对高并发？
 


对于高并发的接口，我们频繁对 DB 进行操作的话不仅对性能会有非常大的影响，甚至可能使其宕机，这是极有可能发生而且不可逆的现象。所以我们的目标是**尽量使主线程不对 DB 进行操作**。
 


1. 在秒杀活动开始前，通过定时任务将秒杀商品的核心数据预热加载到 Redis 缓存中，确保活动开始时可直接读取缓存数据，避免大量请求直接穿透到数据库。
2. 然后因为我们不对 DB 进行操作，所以库存方面我们可以在 redis 中为每个秒杀商品维护一个**库存键**，只要库存大于 0 进行扣减，反之则拒绝请求。
3. 用户下单成功后，主线程仅做必要校验和 redis 库存扣减，生成的订单数据**不直接写入数据库**，而是发送到**消息队列**进行异步处理。
4. 在秒杀活动结束后，通过定时任务读取 redis 中记录的最终库存变化数据。该任务**异步更新**秒杀商品表中的实际库存。
5. 在进入核心业务逻辑接口**前**，设置**拦截器**对请求参数进行**格式校验**，快速过滤掉明显不合法或恶意请求，减轻后端压力。
 


### （三）如何实现一人一单和防止超卖？
 


针对一人一单，我们可以在中为每个秒杀商品维护一个**Set 结构**的键，用于存储已成功下单的用户 ID，在每次发起下单请求的时候进行校验即可。
 


针对超卖问题，由于超卖是因为高并发线程问题所引发的，所以我们应该确保获取库存以及删减库存的原子性操作，所以在这里我们要用到**Lua 脚本**。
 


为了减少频繁的网络请求，所以我们应该将**对 redis 的所有操作**都封装到脚本中，将多次请求缩减到一次。
 


### （四）所引发的问题？
 


对于 MQ，最常见的问题就是**消息发送失败以及重复消费**，对此我们应该启用 RabbitMQ 的生产者确认机制，当消息发送失败或者消息未被确认的时候**立即重新发送**，连续三次失败后我们就应该回滚并返回错误结果。
 


然后是重复消费问题，我们应该在接收到消息之后进行幂等性检查，也就是在 Redis 中为每条消费的消息设置一个**短暂的标记键**，每次收到消息时进行校验，如果已经有数据则直接跳过该消息，反之则进行后续操作。最后在操作完成后删除标记键，如果操作过程中出现异常，则立刻进行**数据回滚**并返回下单失败的提示。
 


然后是 redis，如果在秒杀过程中 redis**宕机**，很容易想到用 DB 作为备用方案，但是这反而会导致同一时间大量的请求打到 DB 上反而压垮 DB，更合理的策略是**立即熔断**，**返回秒杀活动结束或系统繁忙的错误提示**，停止接受新的秒杀请求。
 


但此时肯定有部分订单是生成成功的，所以我们应该继续执行更新库存的，但是此时 redis 已经宕机了，无法读取到库存数据，那该怎么办呢。这时我们可以直接读取 DB 中秒杀商品表中对应商品的订单数量，然后通过计算进行更新即可。

```java
package com.yilena.seckill.config;
 
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.io.ClassPathResource;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.data.redis.core.script.RedisScript;
import org.springframework.data.redis.listener.RedisMessageListenerContainer;
import org.springframework.data.redis.serializer.StringRedisSerializer;
 
@Configuration
@Slf4j
public class RedisConfig {
 
    @Bean
    public RedisTemplate redisTemplate(RedisConnectionFactory redisConnectionFactory) {
        log.info("开始创建redis模板对象...");
        RedisTemplate redisTemplate = new RedisTemplate();
        //设置redis的连接工厂对象
        redisTemplate.setConnectionFactory(redisConnectionFactory);
        //设置redis key的序列化器
        redisTemplate.setKeySerializer(new StringRedisSerializer());
        return redisTemplate;
    }
 
    @Bean(name = "seckillScript")
    public RedisScript<Long> seckillScript() {
        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setLocation(new ClassPathResource("scripts/seckill.lua")); // 确保路径正确
        script.setResultType(Long.class);
        return script;
    }
}
```

#### 2.RabbitTemplate 配置类
 


```java
package com.yilena.seckill.config;
 
import com.yilena.seckill.constant.RabbitMqConstant;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.amqp.core.Binding;
import org.springframework.amqp.core.BindingBuilder;
import org.springframework.amqp.core.DirectExchange;
import org.springframework.amqp.core.Queue;
import org.springframework.amqp.rabbit.config.SimpleRabbitListenerContainerFactory;
import org.springframework.amqp.rabbit.connection.ConnectionFactory;
import org.springframework.amqp.rabbit.core.RabbitTemplate;
import org.springframework.amqp.support.converter.Jackson2JsonMessageConverter;
import org.springframework.amqp.support.converter.MessageConverter;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
 
@Slf4j
@Configuration
@RequiredArgsConstructor
public class RabbitMqConfig {
 
    private final ConnectionFactory connectionFactory;
 
    @Bean
    public MessageConverter jsonMessageConverter() {
        return new Jackson2JsonMessageConverter();
    }
 
    @Bean
    public RabbitTemplate rabbitTemplate(ConnectionFactory connectionFactory) {
        // 实例化
        RabbitTemplate template = new RabbitTemplate(connectionFactory);
        // 设置消息转换器为jsonMessageConverter，确保消息以JSON格式进行发送和接收
        template.setMessageConverter(jsonMessageConverter());
        return template;
    }
 
    // 创建监听容器工厂
    @Bean
    public SimpleRabbitListenerContainerFactory rabbitListenerContainerFactory(ConnectionFactory connectionFactory) {
        SimpleRabbitListenerContainerFactory factory = new SimpleRabbitListenerContainerFactory();
        // 设置连接工厂，用于后续创建的监听器容器连接到RabbitMQ
        factory.setConnectionFactory(connectionFactory);
        factory.setMessageConverter(jsonMessageConverter());
        return factory;
    }
 
    // 创建交换机
    @Bean
    public DirectExchange directExchange() {
        return new DirectExchange(RabbitMqConstant.SECKILL_EXCHANGE);
    }
 
    // 创建队列
    @Bean
    public Queue seckillQueue() {
        return new Queue(RabbitMqConstant.SECKILL_QUEUE);
    }
 
    // 绑定队列和交换机
    @Bean
    public Binding binding(DirectExchange directExchange , Queue seckillQueue) {
        return BindingBuilder.bind(seckillQueue)
                .to(directExchange)
                .with(RabbitMqConstant.SECKILL_BINDING_KEY);
    }
}
```

```java
            RabbitTemplate rabbitTemplate = (RabbitTemplate) bean;

                if (!ack) {
                    log.error("消息发送失败: {}", correlationData != null ? correlationData.getId() : "unknown");
                    retryService.asyncRetry(correlationData);
                }
            });
        }
        // 返回处理后的bean实例
        return bean;
    }
}
```

```java
import java.util.ArrayList;

public class ThreadPoolUtil {
 
    public static <T> List<List<T>> slicingData(List<T> dataList, Integer splitSize) {
 
        int dataSize = dataList.size();
        int groupSize = dataSize / splitSize;
        if (dataSize % splitSize != 0) {
            groupSize = groupSize + 1;
        }
 
        List<List<T>> chunks = new ArrayList<>(groupSize);
        for (int i = 0; i < groupSize; i++) {
            int fromIndex = i * splitSize;
            int toIndex = fromIndex + splitSize;
            List<T> suppliesReadData;
            if (i == groupSize - 1) {
                suppliesReadData = dataList.subList(fromIndex, dataList.size());
            } else {
                suppliesReadData = dataList.subList(fromIndex, toIndex);
            }
            chunks.add(suppliesReadData);
        }
        return chunks;
    }
 
    public static void allFuturesWait(List<CompletableFuture<Void>> completableFutures) {
        // 等待所有异步任务完成后，可以继续进行下一步操作
        CompletableFuture<Void> allFutures = CompletableFuture.allOf(completableFutures.toArray(new CompletableFuture[0]));
        allFutures.join();
    }
}
```

```java
package com.yilena.seckill.utils;
 
import org.springframework.stereotype.Component;
 
@Component
public class SnowFlake {
 
    private SnowFlakeProperties properties;
 
    public SnowFlake() {
    }
 
    public SnowFlake(SnowFlakeProperties properties) {
        this.properties = properties;
    }
    public synchronized  long getID(){
        //获得当前时间
        long now = System.currentTimeMillis();
        long lastTimeStamp = properties.getLastTimeStamp();
        //当前系统时间小于上一次记录时间
        if (now < lastTimeStamp){
            throw new RuntimeException("时钟回拨异常");
        }
        //相同时间 要序列号进制增量
        if (now == lastTimeStamp){
            //防止溢出
            long sequence = properties.getSequence();
            sequence = (sequence + 1) & properties.getSequenceMask();
            //更新sequence 的值
            properties.setSequence(sequence);
            if (sequence == 0L){
                //溢出处理
                try {
                    Thread.sleep(1L);
                } catch (InterruptedException e) {
                    throw new RuntimeException(e);
                }
                //获取下一毫秒时间 （有锁）
                now = System.currentTimeMillis();
            }
        }else {
            //置0
            properties.setSequence(0L);
        }
        //记录当前时间
        properties.setLastTimeStamp(now);
        return ((now - properties.getStartTimeStamp()) << properties.getTimeStampIndex()) |
                (properties.getDataCenterID() << properties.getDataCenterIndex())|
                (properties.getWorkID() << properties.getWorkIDIndex()) | properties.getSequence();
    }
}
```

```java
package com.yilena.seckill.utils;
 
public class SnowFlakeValidator {
 
    public static boolean isSnowFlakeID(long id, SnowFlakeProperties props) {
        // 验证序列号：必须在 0 ~ sequenceMask 之间
        long sequenceMask = props.getSequenceMask();
        long sequence = id & sequenceMask;
        if (sequence < 0 || sequence > sequenceMask) {
            return false;
        }
 
        // 验证数据中心ID
        long dataCenterBits = props.getWorkIDIndex() - props.getDataCenterIndex();
        long dataCenterMask = (1L << dataCenterBits) - 1;
        long dataCenterID = (id >> props.getDataCenterIndex()) & dataCenterMask;
        if (dataCenterID != props.getDataCenterID()) {
            return false;
        }
 
        // 验证机器ID
        long workIDBits = props.getTimeStampIndex() - props.getWorkIDIndex();
        long workIDMask = (1L << workIDBits) - 1;
        long workID = (id >> props.getWorkIDIndex()) & workIDMask;
        if (workID != props.getWorkID()) {
            return false;
        }
 
        // 验证时间戳
        long timeStamp = (id >> props.getTimeStampIndex()) + props.getStartTimeStamp();
        if (timeStamp < props.getStartTimeStamp()) {
            return false;
        }
 
        return true;
    }
}
```

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class SeckillQueueListener {
 
    private final OrderDao orderDao;
    private final UserDao userDao;
    private final StringRedisTemplate stringRedisTemplate;
 
    @RabbitListener(queues = RabbitMqConstant.SECKILL_QUEUE)
    public void handleSeckillQueue(Order order) {
        log.info("秒杀商品信息队列接收到信息，开始处理id为 {} 的订单",  order.getId());
        // 幂等性检查，避免重复消费

        // 如果返回false，则说明该订单已经被处理过，直接返回
        if (Boolean.FALSE.equals(isNew)) {
            log.warn("订单重复消费: {}", order.getId());
            return;
        }
 
        try {
            // 检验用户id是否存在
            Integer isExist = userDao.isExist(order.getUserId());
            // 用户不存在，回滚数据
            if (isExist == 0) {
                throw new RuntimeException("用户不存在");
            }
            // 处理订单
            order.setStatus(1);
            orderDao.insert(order);
        } catch (Exception e) {
            log.error("订单处理失败: {}", order.getId(), e);
            // 回滚Redis库存
            stringRedisTemplate.opsForValue().increment(
                    RedisKeyConstant.SHOP_SECKILL_COUNT_KEY + order.getShopId()
            );
            // 移除订单记录
            stringRedisTemplate.opsForSet().remove(
                    RedisKeyConstant.SHOP_SECKILL_ORDER_KEY + order.getShopId(),
                    order.getUserId().toString()
            );
        } finally {
            // 处理完成后删除标记
            stringRedisTemplate.delete(key);
        }
    }
}
```
 


因为不会出现重复下单，所以如果 isNew 为 false 那只能是重复消费的情况。

```java
package com.yilena.seckill.task;
 
import cn.hutool.json.JSONUtil;
import com.yilena.seckill.constant.RedisKeyConstant;
import com.yilena.seckill.dao.OrderDao;

import com.yilena.seckill.utils.ThreadPoolUtil;
import jakarta.annotation.PreDestroy;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;
 
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;
 
@Slf4j
@Component
@RequiredArgsConstructor
public class UpdateShopCountTask {
 
    private final SeckillDao seckillDao;
    private final StringRedisTemplate stringRedisTemplate;
    private final OrderDao orderDao;
    private final ExecutorService executor = Executors.newFixedThreadPool(10);
 
    // 销毁线程池
    @PreDestroy
    public void destroy() {
        // 禁止新任务提交，等待已提交任务执行完毕
        executor.shutdown();
        try {
            // 最多再等待60秒，如果超时直接强制关闭线程池
            if (!executor.awaitTermination(60, TimeUnit.SECONDS)) {
                executor.shutdownNow();
            }
        } catch (InterruptedException e) {
            executor.shutdownNow();
            Thread.currentThread().interrupt();
        }
    }
 
    // 假设十点十分结束秒杀活动
    @Scheduled (cron = "0 10 10 * * ?")
    public void updateShopCount () {
        log.info("开始更新秒杀活动DB库存余额，执行时间：{}", LocalDateTime.now());
 
        // 获取所有秒杀商品id
        List<Long> shopIds = seckillDao.getAllShopIds();
 
        // 进行分片, 提高效率
        List<List<Long>> splitData = ThreadPoolUtil.slicingData(shopIds, 100);
 
        // 开启线程并行进行数据更新
        splitData.forEach(batch -> {
            List<CompletableFuture<Void>> futures = new ArrayList<>();
 
            batch.forEach(shopId -> {
                CompletableFuture<Void> future = CompletableFuture.runAsync(() -> {
                    try {
                        // 检查redis中的库存余额
                        String countStr = stringRedisTemplate.opsForValue().get(RedisKeyConstant.SHOP_SECKILL_COUNT_KEY + shopId);
                        if (countStr != null) {
                            // 获取redis中的库存余额
                            Integer count = Integer.parseInt(countStr);
                             // 更新DB库存余额
                            seckillDao.updateShopCount(shopId, count);
                        }else{
                            // redis数据可能出了问题，所以需要通过计算DB中对应订单的数量来获取库存余额
                            Integer count = orderDao.getShopOrderCount(shopId);
                            seckillDao.updateShopCountByOrderCount(shopId, count);
                        }
                    }catch (Exception e){
                        log.error("更新秒杀活动DB库存余额失败,商品ID：{}", shopId , e);
                    }
                }, executor);
                futures.add(future);
            });
 
            // 等待当前批次完成
            ThreadPoolUtil.allFuturesWait(futures);
        });
 
        log.info("更新秒杀活动DB库存余额完成，结束时间：{}", LocalDateTime.now());
    }
}
```
