# 私藏推荐新增游戏分类

## 1. 背景与目标

私藏推荐已支持小说、漫画、番剧、开源项目和其他分类。按用户要求增加“游戏”，让游戏条目可以通过现有分类筛选、搜索和排序功能浏览。

## 2. 实现

- 在 `src/features/recommendations/model.ts` 的内置分类列表加入“游戏”；空分类也会出现在筛选按钮中，条目数由当前 JSON 数据统计。
- 在 `src/data/recommendations.json` 增加一条 `demo: true` 的游戏界面示例，明确标记其为占位数据，不伪装成个人真实推荐或评分。
- 更新推荐页描述、介绍文案和维护说明；没有新增样式或改动分类交互。

## 3. 数据维护

真实游戏推荐继续使用 `src/data/recommendations.json`。填写真实名称、封面、链接或个人评分后，应移除 `demo: true`，并将示例描述替换成自己的体验；字段约束见 `src/features/recommendations/README.md`。
