# 歌单页嵌入网易云音乐歌单

## 1. 目标

将用户提供的三个网易云音乐歌单嵌入 `/music` 页面，并让全局右下角背景音乐播放器使用相同歌单数据，沿用项目现有播放器和交互，不改播放器 UI。

## 2. 实现方式

`src/pages/music.md` 使用 `{% media audio %}` 媒体块。三个歌单作为三个可切换的播放列表组，由现有 `AudioPlayer` 客户端组件渲染。

全局右下角播放器使用 `config/site.yaml` 的 `bgm.audio` 配置，由 `src/constants/site-config.ts` 组装并通过 `src/layouts/AppShell.astro` 传给 `GlobalBGMPlayer`。已将其三组歌单同步为与 `/music` 完全相同的标题和网易云 URL。

歌单名称与 ID：

| 歌单 | ID |
| --- | --- |
| ヰ世界情緒（异世界情绪） | `7991458296` |
| 美波 美波 美波！！！ | `2964644014` |
| DAZBEE | `9841149241` |

Meting 客户端 `parseMusicUrl()` 从网易云 URL 中提取歌单 ID，再请求配置的 Meting API。`uct2` 查询参数保留在页面源数据中，但当前解析器只向 Meting 服务传递 `server`、`type` 和 `id`；播放数据由 Meting 服务按公开歌单 ID 获取。

## 3. 风险和边界

- 播放器加载与播放依赖外部 Meting API、网易云歌曲权限和浏览器网络环境。
- Meting API 返回歌单曲目不代表每首曲目都可播放；版权、地区或会员限制可能导致个别歌曲播放失败。
- 歌单页和全局播放器目前分别维护于 Markdown 媒体块与 YAML 配置中；后续变更歌单时需同步更新两处，避免再次出现不一致。

## 4. 验证
