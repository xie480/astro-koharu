# 方法与边界

## 本轮范围

快照日期为 2026-10-30，来源为 `astro-koharu` 在该时刻 Git 跟踪的 59 个博客文件（HEAD 见 `_meta/corpus-manifest.json`）。读取的是当时工作区字节，不是承诺线上部署版本。另有一篇未跟踪的新稿，没有混入本轮。

按用户要求，本轮没有加载根目录 `agent.md` 或 `docs/writing/文风.md`，不从已有规范逆推语料规律。使用 `writing-dna-skill` 的 L1—L6 方法和 `skill-creator` 的包组织与验证方法；不依赖这些 Skill 才能使用本包。

59 份原文均随包冻结，记录源路径、日期、SHA-256。三个分析分组完整阅读了自然语言正文、章节、表格、引用、代码前后解释；代码内部主要审阅关键片段、分布与作用，没有逐行技术审计。C057/C058 去掉 frontmatter 后正文哈希一致，原文均保留，汇总采用一次计数。统计列名中的 58 是不同正文数，不是声称有 58 篇可靠原创作品。

逐篇元数据覆盖 59/59，包含体裁、主题、引子、结构、结尾、素材、声音、特殊处和原始行号引文。手工功能分类与博客原有 categories 不同；`family` 用于选样路由，`article_type` 保留较细的人工观察。`style_weight` 是样本说明，不是技术正确性评分，汇总数值也未据此主观加权。

## L1 统计口径

脚本 `scripts/analyze_corpus.py` 用标准库解析 Markdown：去掉 frontmatter、代码围栏、标题、表格行、独立图片和链接地址；保留项目符号文字与普通引用。另排除以时间戳、Java 异常、日志级别或 SQL 命令开头的引用日志行，本轮识别 3 行，避免长报错被计成长句。行间空白合并，字符数不含空白。段落遇到空行、标题、代码、表格或列表新条目切分，因此“段落平均长度”混入大量列表项，不能等同长文自然段长度。

句子以中文 `。！？` 和英文 `?!` 为边界。英语句点、分号、换行不作为句界，以免技术标识符被小数点切碎；无句末标点的独立条目也按片段计数。句长包含正文技术名词与标点，排除空白。短句为 ≤15 字符，长句为 ≥50 字符。它是可复现的近似统计，不能解释为严格语言学测量。

词性表额外运行 jieba 0.42.1 默认词典，保留至少两字符的 token：`n*` 归名词、`v*` 归动词、`d` 为副词、`eng` 单列英语词。自动词性未逐项人工复标，专有名词和歧义词可能误分。脚本还提供固定候选词表的子串匹配，词项可以重叠、大小写敏感；它与分词表不是同一种统计，不能互换频数。

最初 pip 未获得发行包；随后从 PyPI 获得 jieba 0.42.1 源码，在项目忽略的 `.cache/` 中解包，实际完成了词性统计。第三方源码和模型不进入交付包。默认运行统计脚本只产生标准库口径；重现本轮词性表需可选的 jieba 源目录：

```bash
python scripts/analyze_corpus.py --jieba-root /path/containing/jieba
```

重算会更新 `_meta/corpus.json`、`_meta/metrics/` 中逐篇详细指标与 `statistics.json`，不会覆盖 raw。`--snapshot` 仅用于新的空包创建快照，已有 raw 时拒绝覆盖。本文的路由分类和报告仍需人工更新；重算指标不等于重新蒸馏风格。

## L2—L5 如何形成结论

三组分别细读 C001—C024、C025—C045、C046—C059，将可观察句法、结构动作和反例写入各自标注。根代理汇合后，以体裁优先、日期辅助组织模板。每个主要结论保留代表原文，避免只看最新几篇或把唯一随笔平均到技术教程。

从“多篇出现某种取舍”推断写作倾向，与作者实际心理、是否使用 AI、某个技术结论是否成立，是不同层面的判断。本包不提供后两类认证。没有采用去 AI 味禁词清单筛掉真实存在的对比、比喻、长总结等写法。

## L6 图片核验

对 C004、C009、C023、C050、C059 共 5 篇逐张打开全部 11 张正文图片，结合上下文分类。来源、哈希、尺寸及功能见 `_meta/image-audit.json`。远程图片下载到本次项目的忽略缓存供视觉查看，未把远程截图或私有路径作为 Skill 资源依赖。

样本有目的地覆盖排障证据和业务流程，不代表全站随机样本；没有核验其他正文图、全部封面、实际网页 CSS、图片来源身份或所有远程链接可用性。因此不规定字体字号和统一色系，也不把样本分类比例说成全站比例。

## 使用与效果边界

入口和资源结构验证只能证明包可以读、证据可以追溯、选样能运行；不能证明任何模型都可达到某个风格分数。独立试写的实际结果在项目任务文档记录，不伪装为盲评、A/B 实验或作者认可。

本包完整自包含的是写法、索引和原文。原文里的远程媒体仍可能失效，但不影响文本校准。只有一篇个人随笔、一篇工具介绍，对未覆盖的生活题材应保持弱推断；如需更稳定的相似性，应补充同类文章并重新分析。

未来更新先确定新语料范围，建立新的快照与日期，再重做受影响的标注、统计和反例；保留本轮结论的来源，不把多次快照覆盖成无法复盘的一套数字。
